# Seeonee decision register

Version 1.0 • September 25 2026 • Prepared for Diego Araujo

Every decision in this register was made on Diego's behalf under his instruction to "always follow the recommended choice" (project brief, 2026-09-25); none was confirmed by him in conversation, so each row states the alternatives that were on the table and why the recommended one won. D01-D16 are the locked decisions of the project brief and are recorded as written there; D17 onward are the concept-panel choices, the synthesis choices and the derived stack, deployment and production choices that docs/GDD.md, docs/PLAN.md and docs/RESEARCH.md expand. To override any row: add a dated row directly under it (same ID plus a letter, for example D28a), mark the old row "superseded", then edit every section named in "Where it lives" in the same commit and re-run the tests or scenarios that the row names; the pull request template asks for the DECISIONS row. Rows that change a feel number also change docs/PLAN.md §4.8 and `src/game/data/tuning.ts`, which must hold the same values.

Column key: "Where it lives" cites GDD (docs/GDD.md), PLAN (docs/PLAN.md) and RESEARCH (docs/RESEARCH.md) sections. Confidence: High means locked or verified on a primary source; Medium means an initial value that a playtest or a milestone tunes; Low means it depends on an unverified engine behavior or an M0 spike and has a named fallback. Spelling is American; character names use Kipling spellings.
