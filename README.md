# Seeonee (working title)

A single-player 2D exploration platformer for the browser: Mowgli climbs the tree-roads, creepers and ruins of Kipling's Seeonee hills, gathers 15 moon-stones per level until the level's elder agrees to lead him on, and faces four bosses that end with fear defeated, never an enemy destroyed.

Based on the public-domain Mowgli stories of Rudyard Kipling (1894-95). Not affiliated with, endorsed by or sponsored by The Walt Disney Company or the 1994 Virgin Interactive game.

Baseado nas histórias de Mowgli, de Rudyard Kipling (1894-95, domínio público). Sem afiliação, endosso ou patrocínio da The Walt Disney Company ou do jogo de 1994 da Virgin Interactive.

## Status

M0-M3.4 implemented (2026-10-01): `npm run typecheck`, `npm run test` (162 Vitest unit tests) and `npm run build` are green, and six Playwright e2e tests pass against the built output (the M1 smoke test, the full Title-to-L1 menu flow, L2 through the B1 boss to Kaa's exit, L4's hut door/buffalo/B2 boss door wiring, L6's pouch/altar/Thuu's-gate/B3 boss door wiring, and L8's rally/slow-water/B4 boss door wiring). The menu flow, save system, i18n dictionary, touch controls, HUD, L1 Council Rock, L2 Cold Lairs/B1, L3-L4/B2, and L5-L6/B3 are unchanged from M2/M3.1/M3.2/M3.3 (see those sections below and `docs/DECISIONS.md` D89a-h, D94a-n, D95a-i, D96a-k and D97a-h).

M3.4 (Zone 4: L7 Bee Rocks, L8 The Ford and boss B4) adds garlic as the timed item (no lit/toggle state like Red Flower -- rubbing it starts protection outright, and a second bed just tops the meter back up), hives as Turret-script spawners that release a bee cloud (a new S3 Diver script -- a hazard that cannot be hit at all, pursuing within a leash of its hive and returning home when the player steps outside it or garlic is active), boulders (the exact `advanceOnHit` carry-platform mechanic built for the buffalo in M3.2, extended to also smash any hive it rolls into), dhole scout pairs (the pariah-dog Charger lunge reused unchanged), the rallied wolf (a plain stone with a `wolf` skin and its own HUD label, not a second inverted-quota system), slow water (a trigger halving run speed) and safe water (a trigger exempting a zone from the pit/fall check), floating logs (a plain carry-platform shuttle), and Pack strength -- a paw meter (`logic/boss/PackStrength.ts`) seeded from the rallied count that lets the Pack intercept a dhole's hit some percentage of the time. B4 Red Dog is the fourth boss on S7 BossMachine (a leader rush and leap across three waves), with two always-present dholes flagged to roll the Pack intercept instead of counting as a boss hit, and no Dance-style resolution -- defeat alone opens Phao's exit. `public/game/maps/l7.tmj`/`l8.tmj` (gray-box, generated by `tools/gen-l7-map.mjs`/`gen-l8-map.mjs`) exercise every one of these.

Verified live in headless Chromium end to end, including the garlic-suppresses-detection/hive-trigger/bee-cloud pursue-contact-return cycle, a boulder smashing its target hive, a floating log carrying a rider tick-by-tick, and both outcomes of the Pack-intercept roll forced deterministically. One real production bug turned up and was fixed: the dhole contact-damage check re-rolled the Pack intercept and re-applied a paw loss on every tick of an overlap instead of once per hit, since the paw cost sat outside the player's own i-frames gate that already protected pip damage from the same thing (`docs/DECISIONS.md` D98f).

Not yet done, all needing a human or a tool unavailable in this sandbox: hand-authoring L1-L8 in the real Tiled 1.12.2 editor (the GDD's own plan re-authors L1 as a tutorial pass in M4 anyway); any real character art or audio (still gray-box rectangles and silence); the GitHub Projects board, the Netlify site and its first deploy; the M2/M3.1/M3.2/M3.3/M3.4 playtest rounds; the storybook map's other pages and the Extras screen; Buldeo's fail-free teaching variant (GDD §10.7 beat 1). Content is now complete through all four zones and bosses; the next step is M4 Content Complete (the Spring Running, farewell cards, Outsong credits, Honey Hollow, the remaining storybook map pages, tiers wired end-to-end, Retro mode, the L1 tutorial re-author pass) per `docs/PLAN.md` §12.3.

## What the game is

| Item | Value |
| --- | --- |
| Genre | Collect-and-exit platformer: 15 collectibles per level, a quota of 8 / 10 / 12 by difficulty tier, an exit character once the quota is met, a boss per zone |
| Structure | 4 zones x 2 levels, 4 bosses, the non-combat Spring Running finale, a 100% epilogue, one bonus stage in the must tier |
| Modes | Modern (default: no lives, no clock, autosaving checkpoints, instant respawn) and Retro (optional: 3 lives, a 6:00 clock); tiers Cub / Wolf / Lone Wolf; Assist Mode |
| Tone | Nobody bleeds, the player kills nothing, humans are fearful not villains, one gently handled death |
| Languages | English and Brazilian Portuguese from day one, with Kipling's spellings in both |
| Platform | Desktop browsers with keyboard or gamepad, phones and tablets with touch; hosted on Netlify |
| Presentation | 320x180 pixel art at integer zoom, 16 px tiles, 60 Hz fixed-step simulation, one 40-color palette |
| Play time | 60-90 min for a quota run, 2-3 h for 100% |

## Planned stack

Phaser 4.2.1 pinned exactly (phaser@3.90.0 is the fallback), TypeScript 7.0.x, Vite 8.3.x, Vitest 5.0.x, @playwright/test 1.63.x, Tiled 1.12.2, Aseprite or Pixelorama, Node 24 with npm and a committed lockfile, Netlify static hosting, GitHub Actions for tests. Arcade Physics only; runtime assets under `public/game/`. Versions were verified on 2026-09-25 (`docs/RESEARCH.md` §8).

## Running locally

Node 24 (`.nvmrc`; Node >=22.12 also works locally). `npm install`, then `npm run dev` (opens on `http://localhost:8080`; the full Title menu boots by default, or add `?level=gym` / `?level=l1` / `?level=l2` / `?level=l3` / `?level=l4` / `?level=l5` / `?level=l6` / `?level=l7` / `?level=l8` to jump straight into a level, and `F3` in dev builds for the debug overlay), `npm run test` for the Vitest suite, `npm run build && npm run preview` for a production build, `npm run e2e` for the Playwright e2e tests. `npm run typecheck` and `npm run credits` are also available. Tiled 1.12.2 and an art tool (Aseprite or Pixelorama) are needed from M4 on, when real levels and art replace the M1-M3.4 gray-box.

## Planned repository layout

- `src/game/logic/` and `src/game/data/`: pure TypeScript rules and tuning values, unit-tested, never importing the engine.
- `src/game/scenes/`: Boot, Title, SaveSlot, TierPick, Map, Card, Loading, Play, Hud, Pause, Options and Results scenes; `PlayScene.ts` is the only gameplay file that touches engine objects.
- `src/game/i18n/`: the EN/PT-BR typed dictionary and the plural-aware `t()` translator.
- `public/game/`: runtime assets (sprites, tilesets, maps, audio, fonts) listed in one manifest.
- `tests/unit/` and `tests/e2e/`: Vitest rules tests and one Playwright smoke test.
- `tools/`: credits generation, level validation and art export scripts.
- `docs/`: the four documents above and the playtest observation sheets.

## Names and spelling

In-game names use Kipling's spellings in both languages (Mowgli, Bagheera, Baloo, Shere Khan, Kaa, Akela, Raksha, Hathi, Chil, Thuu, Grey Brother). The word "mogli" is the repository folder name only and never appears in the title, logo, URL slug, package name or store metadata (`docs/DECISIONS.md` D03).

## Feedback and privacy

Closed playtests run on Netlify Deploy Previews with an in-game "Copy diagnostics" button and a short form; nothing is collected automatically. A public launch may add anonymous gameplay statistics only behind a first-run notice with equal "OK" and "Don't send" buttons, and the privacy notice ships in EN and PT-BR (`docs/PLAN.md` §11).
