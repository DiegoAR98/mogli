# Seeonee (working title)

A single-player 2D exploration platformer for the browser: Mowgli climbs the tree-roads, creepers and ruins of Kipling's Seeonee hills, gathers 15 moon-stones per level until the level's elder agrees to lead him on, and faces four bosses that end with fear defeated, never an enemy destroyed.

Based on the public-domain Mowgli stories of Rudyard Kipling (1894-95). Not affiliated with, endorsed by or sponsored by The Walt Disney Company or the 1994 Virgin Interactive game.

Baseado nas histórias de Mowgli, de Rudyard Kipling (1894-95, domínio público). Sem afiliação, endosso ou patrocínio da The Walt Disney Company ou do jogo de 1994 da Virgin Interactive.

## Status

M0-M3.2 implemented (2026-10-01): `npm run typecheck`, `npm run test` (148 Vitest unit tests) and `npm run build` are green, and five Playwright e2e tests pass against the built output (the M1 smoke test, the full Title-to-L1 menu flow, L2 through the B1 boss to Kaa's exit, and L4's hut door/buffalo/B2 boss door wiring). The menu flow, save system, i18n dictionary, touch controls, HUD, L1 Council Rock and L2 Cold Lairs/B1 are unchanged from M2/M3.1 (see those sections below and `docs/DECISIONS.md` D89a-h, D94a-n and D95a-i).

M3.2 (Zone 2: L3 Water Truce, L4 Man-Pack and boss B2) adds the S4 carry-platform flag (a back-and-forth waypoint walker reused for Hathi's sons, a buffalo bridge and Rama), the advanceOnHit flag (a nut sends an idle buffalo charging through a breakable thorn fence), the bounce flag (a trunk-launch pad), the S5 truce zone (every enemy stands down, a throw drops silently rather than flying), two new S3 script variants (a range-gated, straight-shooting quill-pig built on the Lobber script; a telegraph-charge-contact-damage pariah dog built on the Charger script), hut doors (the Master Words gate's own machinery with a shorter 0.25 s hold), and the clod — wired into actual play for the first time, though declared dormant in `data/` since M1/M2. B2 The Lame One in the Ravine is the second boss on S7 BossMachine (generalized off its M3.1-only B1 constant): a lame charge and roar in phase 1, a pounce in phase 2, a swipe and falling rocks while riding Rama in phase 3, with no Dance-style resolution (GDD §8.3's own stampede ending) — defeat alone opens the path to Grey Brother's exit. `public/game/maps/l3.tmj`/`l4.tmj` (gray-box, generated by `tools/gen-l3-map.mjs`/`gen-l4-map.mjs`) exercise every one of these.

Verified live in headless Chromium end to end, including forcing B2 to defeated and riding a carry platform tick-by-tick. That verification caught and fixed three more real bugs (documented in `docs/DECISIONS.md` D96j): every new enemy-placement helper in both level generators double-scaled its spawn position by the tile size (a cobra meant for x=384 landed at x=6144); a carry platform's `waypoints` property duplicated its own starting point, so an advanceOnHit buffalo computed a zero-length advance and never reached its fence; and the first carry-platform ride dropped the rider through the floor within a few ticks, because nudging position by that tick's delta alone lost to gravity `stepPlayer` had already applied having seen no real ground contact — fixed by pinning the rider to the platform's surface outright once "on top" is true, not just nudging toward it.

Not yet done, all needing a human or a tool unavailable in this sandbox: hand-authoring L1-L4 in the real Tiled 1.12.2 editor (the GDD's own plan re-authors L1 as a tutorial pass in M4 anyway); any real character art or audio (still gray-box rectangles and silence); the GitHub Projects board, the Netlify site and its first deploy; the M2/M3.1/M3.2 playtest rounds; the storybook map's other pages and the Extras screen. The next step is M3.3 (Zone 3: L5 Let in the Jungle, L6 King's Treasure and boss B3) per `docs/PLAN.md` §12.3.

## What the game is

| Item | Value |
| --- | --- |
| Genre | Collect-and-exit platformer: 15 collectibles per level, a quota of 8 / 10 / 12 by difficulty tier, an exit character once the quota is met, a boss per zone |
| Structure | 4 zones x 2 levels, 4 bosses, the non-combat Spring Running finale, a 100% epilogue, one bonus stage in the must tier |
| Modes | Modern (default: no lives, no clock, autosaving checkpoints, instant respawn) and Retro (optional: 3 lives, a 6:00 clock); tiers Cub / Wolf / Lone Wolf; Assist Mode |
| Tone | Nobody bleeds, the player kills nothing, humans are fearful not villains, one gently handled death |
| Languages | English and Brazilian Portuguese from day one, with Kipling's spellings in both |
| Platform | Desktop browsers with keyboard or gamepad, phones and tablets with touch; hosted on Netlify |
| Presentation | 320x180 pixel art at integer zoom, 16 px tiles, 60 Hz fixed-step simulation, one 40-color palette |
| Play time | 60-90 min for a quota run, 2-3 h for 100% |

## Planned stack

Phaser 4.2.1 pinned exactly (phaser@3.90.0 is the fallback), TypeScript 7.0.x, Vite 8.3.x, Vitest 5.0.x, @playwright/test 1.63.x, Tiled 1.12.2, Aseprite or Pixelorama, Node 24 with npm and a committed lockfile, Netlify static hosting, GitHub Actions for tests. Arcade Physics only; runtime assets under `public/game/`. Versions were verified on 2026-09-25 (`docs/RESEARCH.md` §8).

## Running locally

Node 24 (`.nvmrc`; Node >=22.12 also works locally). `npm install`, then `npm run dev` (opens on `http://localhost:8080`; the full Title menu boots by default, or add `?level=gym` / `?level=l1` / `?level=l2` / `?level=l3` / `?level=l4` to jump straight into a level, and `F3` in dev builds for the debug overlay), `npm run test` for the Vitest suite, `npm run build && npm run preview` for a production build, `npm run e2e` for the Playwright e2e tests. `npm run typecheck` and `npm run credits` are also available. Tiled 1.12.2 and an art tool (Aseprite or Pixelorama) are needed from M4 on, when real levels and art replace the M1-M3.2 gray-box.

## Planned repository layout

- `src/game/logic/` and `src/game/data/`: pure TypeScript rules and tuning values, unit-tested, never importing the engine.
- `src/game/scenes/`: Boot, Title, SaveSlot, TierPick, Map, Card, Loading, Play, Hud, Pause, Options and Results scenes; `PlayScene.ts` is the only gameplay file that touches engine objects.
- `src/game/i18n/`: the EN/PT-BR typed dictionary and the plural-aware `t()` translator.
- `public/game/`: runtime assets (sprites, tilesets, maps, audio, fonts) listed in one manifest.
- `tests/unit/` and `tests/e2e/`: Vitest rules tests and one Playwright smoke test.
- `tools/`: credits generation, level validation and art export scripts.
- `docs/`: the four documents above and the playtest observation sheets.

## Names and spelling

In-game names use Kipling's spellings in both languages (Mowgli, Bagheera, Baloo, Shere Khan, Kaa, Akela, Raksha, Hathi, Chil, Thuu, Grey Brother). The word "mogli" is the repository folder name only and never appears in the title, logo, URL slug, package name or store metadata (`docs/DECISIONS.md` D03).

## Feedback and privacy

Closed playtests run on Netlify Deploy Previews with an in-game "Copy diagnostics" button and a short form; nothing is collected automatically. A public launch may add anonymous gameplay statistics only behind a first-run notice with equal "OK" and "Don't send" buttons, and the privacy notice ships in EN and PT-BR (`docs/PLAN.md` §11).
